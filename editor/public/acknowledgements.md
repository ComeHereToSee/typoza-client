# 鸣谢

Typoza 使用了下列开源项目,感谢它们的作者与维护者。版本与许可证以发布时打包的版本为准。

## 编辑器

| 项目 | 用途 | 许可证 |
| --- | --- | --- |
| ProseMirror(prosemirror-model、-state、-view、-transform、-tables 等) | 所见即所得编辑内核 | MIT |
| CodeMirror 6 与 Lezer | 代码块与源代码模式 | MIT |
| unified、remark、micromark、mdast 工具集 | Markdown 解析与写回 | MIT |
| KaTeX | 公式渲染 | MIT |
| Mermaid | 图表渲染 | MIT |
| DOMPurify | HTML 净化 | MPL-2.0 或 Apache-2.0(二选一) |
| yaml | YAML 读写 | ISC |
| qrcode-generator | 两步验证二维码 | MIT |
| Emojibase | 表情数据 | MIT |

## 同步辅助进程

| 项目 | 用途 | 许可证 |
| --- | --- | --- |
| Go 标准库与 golang.org/x(crypto、sys、text) | 加密与系统调用 | BSD 3-Clause |
| fsnotify | 文件变化监听 | BSD 3-Clause |
| bbolt | 同步状态存储 | MIT |
| coder/websocket | 实时同步连接 | ISC |

完整许可证文本随各项目源码发布。
