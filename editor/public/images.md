# 使用图片

## 插入

- 粘贴截图、从 Finder 或浏览器拖入图片,或输入 `/图片` 选择文件
- 默认把图片拷进文档旁的 `assets` 文件夹,文件里写相对路径,整个文件夹拿到别处也能正常显示
- 「偏好设置 → 图片」可以改成拷到当前文件夹、指定文件夹、上传到图床,或不拷贝直接引用原路径;文档开头的 YAML 写 `typora-copy-images-to: 文件夹` 时以它为准

还没保存过的新文档,插入的图片先放在 Typoza 的数据目录里;第一次保存时自动搬到文档旁,并改成相对路径。

## 查看

- 双击任意图片放大查看,表格里、带链接的图片也可以;选中图片按空格也能打开
- 放大后 `←` `→` 切换本文所有图片,`+` `-` 缩放,`0` 适合窗口,`1` 原始大小,`Esc` 关闭
- 动图(GIF、APNG、动态 WebP)在文档里直接播放

## 调整

单击选中图片后拖动边角的手柄调整显示大小,或在「缩放」里选比例。调整过大小的图片在文件里写成 `<img>` 标签。放大查看时工具条里可以旋转、复制图片、在 Finder 中显示。
