# 欢迎使用 Typoza

Typoza 是一个 Markdown 编辑器:所见即所得,文件就是普通的 `.md`,用任何编辑器都能打开。

## 像 Notion 一样输入

- 行首输入 `/` 唤出块菜单,继续输入可以过滤(中文、英文、拼音缩写都行)
- `#` + 空格 → 标题,`-` + 空格 → 列表,`[]` + 空格 → 待办,`>` + 空格 → 折叠块,`"` + 空格 → 引用
- 选中文字会出现格式条;`⌘B` 加粗,`⌘K` 加链接,`⌘/` 转换块类型
- 鼠标移到块的左边,拖动「⋮⋮」可以移动整块

## 图片与媒体

- 双击任意图片放大查看(表格里的也可以),`←` `→` 切换,捏合或 `⌘` + 滚轮缩放
- 粘贴网址可以选择「嵌入」:YouTube、哔哩哔哩、Vimeo、Figma 等都能直接播放或预览
- 拖入或粘贴图片、视频、PDF,会自动复制到 `assets` 文件夹

## 常用快捷键

| 功能 | 快捷键 |
| --- | --- |
| 快速打开 | `⌘P` |
| 在文件夹中搜索 | `⇧⌘F` |
| 源代码模式 | `⌃⌘/` |
| 侧边栏 | `⌃⌘S` |
| 专注 / 打字机模式 | `F8` / `F9` |

> [!TIP]
> 偏好设置(`⌘,`)里可以开启云同步:内容在本机加密后才上传,服务器看不到你的文字。
