## 一、需求概述

日常用 Typora 浏览和编写 Markdown 的人,输入习惯与 Notion 不一致,截图混排文档里表格内、带链接的图片也无法放大查看。Typoza 基础版是 macOS 原生 Markdown 编辑器:完整覆盖 Typora 功能,输入方式与快捷键采用 Notion,加强图片灯箱、动图、音视频、在线嵌入、书签、PDF 与附件,纯本地即可完整使用,另有只负责保存的可选端到端加密云同步。多人协作与评论、数据库与看板、同步块、分栏、AI、网页版与 Windows / iOS 本期不做;涉及本机用户与云同步服务。

### 质量要求

| 指标 | 目标 | 口径 |
|---|---|---|
| 冷启动到可输入 | ≤1 秒 | 从点击应用图标到新文档光标可输入【待确认:基准机型】 |
| 打开 5MB Markdown | ≤1.5 秒 | 从发起打开到首屏渲染完成、可滚动 |
| 输入延迟 | p95 ≤16 毫秒 | 在 5MB 文档中连续输入,按键到字符上屏 |
| 安装包 | ≤30MB | DMG 文件体积 |
| 不丢内容 | 崩溃或强退后重启,恢复到最后一次自动保存的内容 | 自动保存在停止输入 1 秒后写盘【假设】 |
| 纯本地 | 未登录云同步时不发起同步相关网络请求 | 检查更新、书签取网页信息、在线嵌入除外,均由用户操作或可关闭 |

**云同步文件状态**(只针对云同步文件夹内的文件)

| 状态 | 进入条件 | 可做操作 | 去向 |
|---|---|---|---|
| 仅本地 | 文件不在云同步文件夹内,或未登录 | 编辑、移入云同步文件夹 | 移入同步文件夹且已登录 → 待上传 |
| 待上传 | 同步文件夹内文件有新保存;或离线、未登录 | 编辑 | 联网且已登录 → 同步中 |
| 同步中 | 开始上传或下载 | 编辑(新修改排在本次之后) | 成功 → 已同步;检测到冲突 → 生成冲突副本后两份各自进入待上传;失败 → 同步失败 |
| 已同步 | 本机与云端最新版本一致 | 编辑、查看云端历史 | 本机保存 → 待上传;云端有新版本 → 同步中 |
| 同步失败 | 空间不足、账号异常等非网络原因 | 查看原因、【重试】 | 重试成功 → 已同步 |
| 已删除 | 任一设备删除该文件 | 在云端回收站【恢复】、【永久删除】 | 恢复 → 同步中 → 已同步;满 30 天或永久删除 → 清除(终态) |

## 三、功能需求

### 3.1 文件与窗口

场景:用户打开单个 md 或整个文件夹浏览、编辑,多个文档用标签页或窗口并排。

| 需求点 | 说明 |
|---|---|
| 打开 | ⌘O、拖到程序坞图标、Finder 双击(设为默认应用后)均可打开;打开文件时其所在文件夹载入侧栏;同一文件已打开时切到已有标签,不重复打开(侧栏、快速打开、链接等全部入口同此规则) |
| 标签与窗口 | ⌘T 新标签、⇧⌘N 新窗口、⇧⌘T 重开最近关闭;⌘+点击本地 md 链接在新标签打开,⌥⇧+点击在新窗口打开;侧栏文件同样适用,右键另有「在新标签页打开」「在新窗口中打开」 |
| 保存 | 自动保存默认开,停止输入 1 秒写盘;关闭自动保存后关窗询问「是否保存更改? 如果不保存,您的更改将会丢失。」;按原编码、原换行符写回;另存为 ⌥⇧⌘S |
| 未命名草稿 | 未保存的新文档停止输入 1 秒后备份到 Typoza 数据目录,重启或网页进程崩溃后恢复到原标签;首次保存或关闭时选「不保存」后删除备份;首次保存默认文件名取首个标题;未保存时插入的图片与媒体,首次保存时搬到「插入图片时」规则指定的文件夹并改写为相对路径(本期未做:源码模式下首次保存不搬运);文件菜单与偏好「文件」页【恢复未保存的草稿】打开未在任何标签里的草稿,没有则打开草稿文件夹;自动保存开启时退出应用不询问未命名文档,草稿留到下次启动恢复【假设】 |
| 外部修改 | 文件被其他程序修改:本机无未保存修改 → 静默重新加载;有未保存修改 → 提示「文件已被其他程序修改」,【重新加载】/【保留我的修改】【假设】 |
| 异常 | 文件不存在提示「目标文件或文件夹不存在。」(打开面板、最近文件、Finder 打开同一文案);只读文件(文件或所在文件夹不可写)可浏览,首次输入时提示「该文件只读,修改无法保存」并给【另存为】,不自动保存,⌘S 改为另存为,状态栏显示「只读」;超过 10MB 以只读源码打开,不能切回所见即所得、不能保存或导出,状态栏不逐字统计;10MB 以内按所见即所得打开,其中 5MB 以内须满足质量要求的打开时长 |
| 写盘失败 | 提示「保存失败:原因。全文已放入剪贴板,可粘贴到新文档后另存。」并给【另存为】;自动保存连续失败时只在第一次写剪贴板 |

### 3.2 编辑器与块

场景:用户在所见即所得界面编辑,内容以块组织,存回 Markdown 后用别的编辑器打开不丢内容。

| 需求点 | 说明 |
|---|---|
| 块与存储 | 段落、标题 1~6、列表、待办、引用、折叠块、标注块、代码、公式、表格、分割线、目录、图片、媒体、嵌入、书签、附件、HTML、YAML 元数据;存储一律标准 Markdown 优先,其次通用 HTML 标签,逐项见对照表与输入规范 |
| 往返保真 | 打开后不编辑直接保存,文件逐字节不变;只改一处时其余内容(含不认识的语法、HTML、`[[链接]]`、`~下标~`)原样保留 |
| 标记显示 | 默认不显示 Markdown 标记;偏好开启「编辑时显示 Markdown 标记」后,光标进入行内样式与标题时展开源码 |
| 块操作 | 悬停显示「+」与「⋮⋮」;Esc 选中当前块,可多块选择;块可拖到侧栏某个文档上,追加到该文档末尾并从当前文档移走;拖拽、复制、移动、删除、转换规则见输入规范第七节 |
| 链接 | 单击显示浮层【打开】【编辑】【复制】【移除】,浮层【打开】在当前标签打开【假设】;悬停显示地址,本地 md 另显示目标文档标题与首段;⌘K 新建链接时剪贴板里的网址自动填入;⌘+点击直接打开(网址用浏览器、`#标题` 文内跳转、本地 md 新标签);脚注、`[[文档名]]` 单击不跳转,⌘+点击才跳转;目标文件不存在时询问「无法打开 X,是否在 Y 新建文件并继续?」;⌘[ 返回;本期未做:带 `#标题` 的本地链接在新标签或新窗口打开时不定位到标题 |
| 字数 | 状态栏显示全文字数;有选区或选中块时显示所选部分;点击弹出词、字符、行与阅读时间(阅读速度见偏好「外观」,默认 382) |

### 3.3 Notion 输入

场景:习惯 Notion 的用户用同样的快捷输入、斜杠菜单和快捷键写 Markdown。

| 需求点 | 说明 |
|---|---|
| 快捷输入 | 块开头 `#`、`-`、`[]`、`1.`、`>`、`"` 加空格及 `---` 即时转换;行内 `**`、`*`、`` ` ``、`~`、`$$` 闭合时转换;代码、公式、链接地址内不触发;全表见输入规范第二节 |
| 已拍板差异 | `>`+空格 = 折叠块(存 `<details><summary>`);`"`+空格 = 引用;⌘/ = 「转换为」菜单;打开已有 `>` 内容仍显示为引用 |
| 斜杠菜单 | 在块开头、空格或标点后输入 `/` 打开(单词中间、网址里、代码里不触发),英文命令与中文名都可搜;条目分基础、行内、媒体、高级、扩展五组,颜色另分「文字颜色」「背景色」两组;无匹配显示「无结果」;Esc 关闭并保留已输入字符;条目全表见输入规范第四节 |
| 文档链接 | `[[` 当场弹出文档菜单,`@` 同样可选文档 → 插入 `[标题](相对路径.md)`,标题取目标文档首个一级标题;选「+ 新建」在当前文档所在文件夹新建同名 md(文档未保存时建在根文件夹【假设】);打开含 `[[文档名]]` 的文件照常识别并原样保留,⌘+点击在新标签打开(同名优先同文件夹) |
| 快捷键 | Notion 键位优先;被挤占的 Typora 功能改到不冲突键位(源代码模式 ⌃⌘/、插入表格 ⌥⇧⌘T、侧边栏 ⌃⌘S、高亮 ⌃⌘H、另存为 ⌥⇧⌘S、打印 ⇧⌘P 等);全表与冲突处理见输入规范第五、六节 |
| 撤回 | 任何自动转换后立即 ⌘Z,撤回为输入的原字符且不再二次转换 |

### 3.4 图片与灯箱

场景:用户浏览标题、段落、表单截图、配置表格混排的文档,需要把任意一张图放大看清。

| 需求点 | 说明 |
|---|---|
| 生效范围 | 灯箱对全部图片生效:正文图片、表格单元格内图片、带链接的图片、HTML `<img>`、动图、网络图片 |
| 单击 | 选中图片:显示四角尺寸手柄(左侧两个向左拖为放大)与浮动工具条(替代文字、缩放比例、转换语法、复制图片、在 Finder 中显示、替换、删除,另有【查看大图】,动图另有【暂停】);带链接的图片单击不跳转,⌘+点击才打开链接 |
| 打开灯箱 | 双击图片,或选中后按空格、⌘↩ → 背景变暗,图片按窗口适配居中;灯箱打开期间编辑区不响应输入 |
| 灯箱内操作 | 滚轮或捏合缩放(10%~800%【假设】);拖动平移;双击在「适配窗口」与「100%」间切换;← / → 按文中顺序浏览本文全部图片,顶部显示「3 / 12」,首尾不循环;【旋转】每次 90°,只改显示不改文件;【复制图片】;【在 Finder 中显示】(网络图片为【在浏览器中打开】);Esc 或点暗处关闭 |
| 尺寸存储 | 拖手柄 → `<img src="路径" width="像素">`(不超过所在段落宽度);菜单选比例(25% / 33% / 50% / 67% / 80% / 100% / 150% / 200%)→ `style="zoom:50%;"`,选 100% 去掉尺寸;未改尺寸的图片保持 `![替代文字](路径)`;有尺寸时转换语法只能用 HTML 格式 |
| 插入与失败 | 粘贴、拖入、插入本地图片默认复制到 ./assets 并写相对路径;目标文件夹不存在时询问「该目录不存在,是否立即创建?」,【创建目录并继续】/【取消】,取消则不插入;加载失败显示占位与原路径,灯箱内提示「图片无法加载」 |
| 图片上传 | 单张上传(格式 ▸ 图像 ▸ 上传图片)、批量上传(上传所有本地图片)与按 YAML 自动上传,都走偏好「图像」页选的上传服务;首次上传前确认将调用第三方服务 |

### 3.5 媒体与嵌入

场景:用户在文档中放动图、视频、音频、在线内容、网页书签、PDF 和附件,在 Typoza 里直接查看。

| 需求点 | 说明 |
|---|---|
| 动图 | GIF、APNG、动态 WebP 自动播放;选中后工具条可【暂停】,暂停时显示首帧;存储同普通图片 |
| 视频与音频 | /video、/audio、拖入或粘贴媒体文件 → 复制到 ./assets → 存 `<video src="路径" controls>` / `<audio src="路径" controls>`;/video、/audio 也可填网址:视频或音频网站地址换成嵌入播放器存 `<iframe>`,直链存 `<video>` / `<audio>`;文内播放,视频可全屏,选中后按空格播放 / 暂停;文件丢失显示「找不到媒体文件」与原路径;文件在但无法解码时保留播放器,下方提示「视频无法播放」/「音频无法播放」与路径 |
| 在线嵌入 | /embed 或粘贴网址后选【嵌入】→ 存 `<iframe src="网址">`;常见视频网站网址自动换成嵌入地址【待确认:首批站点清单】;嵌入内容隔离运行、读不到本地文件;显示前先检查站点是否允许嵌入:离线或连不上显示「无法加载嵌入内容」,站点拒绝时另提示「该网站不允许嵌入,可改为书签卡片」,都带【在浏览器中打开】【改为书签】 |
| 书签卡片 | /bookmark 或粘贴网址后选【书签卡片】→ 取网页标题、描述、图标 → 存`<a href="网址" data-tz-type="bookmark" title="网页描述">网页标题</a>` 单独成段(没有描述时不写 title)【替代实现:单独成段的普通链接若显示成卡片,会改变已有 Typora 文档的观感,改用带类型标记的通用 HTML 精确区分】;新插入的书签取到网页信息后写回标题与描述(描述放 title 属性【假设】),写回不进撤销历史;已存进文件的书签只补显示,不改文件;取不到时用网址作标题并提示「无法获取网页信息,已用网址作标题」 |
| PDF | /pdf 弹出来源浮层:输入网址回车插入,或【选择本机文件…】→ 文内预览,可翻页、缩放;存 `<iframe src="路径.pdf">`【假设】;选中按 ⌘↩:本机 PDF 用系统「预览」打开,网络 PDF 用浏览器打开【假设】 |
| 附件 | /file 或拖入非图片、非媒体、不可导入的文件 → 复制到 ./assets → 存`<a href="assets/文件名" data-tz-type="file">文件名</a>` 单独成段【替代实现:理由同书签】,显示附件卡片(图标、文件名、大小),点击用默认应用打开;docx 等可导入文件拖入时按偏好「导入」或「插入链接」 |

### 3.6 表格

场景:用户编辑配置表、对照表,单元格里有行内格式与截图。

| 需求点 | 说明 |
|---|---|
| 创建 | 输入 `\| 列1 \| 列2 \|` 后回车、/table(直接插入 3 列 × 3 行)、⌥⇧⌘T(先弹行列选择窗:网格最多 6 列 × 10 行,超出可手输,上限 99,行数含表头行【假设】);存 GFM 表格 |
